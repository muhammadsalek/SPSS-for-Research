## Overview

**SPSS for Research** is a hands-on teaching series that walks through statistical data analysis using **IBM SPSS**, built for students and early-career researchers who need practical, research-ready syntax rather than just menu clicks. Each class pairs a **syntax file (.sps)**, **presentation slides (.pdf)**, and a **recorded video lecture** so the material can be followed at any pace.

This repository is maintained under **Salek Data Lab / Salek Research Hub**.

**Series Structure:**

```
SPSS for Research
        │
        ▼
  Class Slides (PDF)     concepts · theory · walkthrough
        │
        ▼
  SPSS Syntax (.sps)     step-by-step commands · reproducible code
        │
        ▼
  YouTube Lecture        live demonstration · explanation
        │
        ▼
  Practice & Output      SPSS output · interpretation · research application
```

## Quick Start

**Requirements:** IBM SPSS Statistics `>= 25`

1. Clone or download this repository
2. Open the relevant class `.sps` file in SPSS Statistics **Syntax Editor**
3. Run line-by-line (`Ctrl + R` on a selected block) while following the matching PDF slides
4. Watch the corresponding YouTube video for full explanation and interpretation of output

```bash
git clone https://github.com/muhammadsalek/SPSS-for-Research.git
```
